# IPL Cricket Data Analysis

This project analyzes IPL match data using Python, Pandas, NumPy, and Matplotlib.

## Project Overview

The analysis focuses on team performance, match results, toss decisions, venues, winning margins, and win percentages.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## Key Analysis

* Total matches and teams
* Team wins and win percentage
* Toss winners and toss decisions
* Matches by venue and city
* Wins by runs and wickets
* Average and maximum winning margin
* Data visualization using Matplotlib

pip install pandas numpy matplotlib
